# Python Crash Course by Eric Matthes

This repository contains chapter-wise code examples and exercises from the book **Python Crash Course** by Eric Matthes.

## Repository Structure

Each chapter has its own folder containing the relevant code files and projects.


## About the Book

Python Crash Course is a hands-on, project-based introduction to programming in Python. It covers Python fundamentals, problem solving, and builds real projects including games and web applications.

## How to Use

1. Clone the repository:
git clone https://github.com/SanketVadchhak/Python-by-Eric-Matthes.git
2. Navigate to the desired chapter folder to explore code and projects.
3. Follow the instructions in each folder or code comments as guidance.

## Technologies

- Python 3.x
- Libraries used depend on each chapter/project
